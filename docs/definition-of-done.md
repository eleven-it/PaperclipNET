# Definition of Done

## Objetivo

Definir cuándo una fase o entregable del proyecto puede considerarse realmente terminado.

## Condiciones mínimas

Un entregable se considera terminado cuando:

1. existe spec aplicable
2. existe test plan aplicable
3. cumple criterios de aceptación
4. no rompe invariantes de seguridad
5. queda documentado de forma suficiente
6. su rollback es concebible/documentable

## Para documentación

- estructura clara
- alcance explícito
- sin contradicciones relevantes
- con trazabilidad

## Para configuración

- coherente con la spec
- sin secretos versionados
- con validación prevista

## Para una fase

- entregables principales presentes
- test plan asociado definido
- riesgos remanentes identificados
- siguiente fase habilitada sin ambigüedad grave
