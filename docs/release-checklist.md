# Release Checklist

## Antes de promover
- [ ] spec aplicable revisada
- [ ] test plan aplicable revisado
- [ ] criterios de aceptación verificados
- [ ] riesgos remanentes documentados
- [ ] rollback posible/documentado

## Configuración
- [ ] config actualizada
- [ ] sin secretos en repo
- [ ] diferencias por entorno documentadas

## Validación
- [ ] listeners comprobados
- [ ] proxy validado
- [ ] healthcheck validado
- [ ] exposición de `3100` descartada

## Operación
- [ ] logs disponibles
- [ ] evidencia mínima conservada
- [ ] responsable de la promoción identificado
