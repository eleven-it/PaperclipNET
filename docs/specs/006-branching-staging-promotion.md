# Spec 006 — Estrategia de ramas, staging y promoción

## Estado

Draft

## Objetivo

Definir cómo se usa `Desarrollo`, `Staging` y la línea base para promocionar cambios de forma controlada.

## Alcance

- propósito de ramas
- criterios de promoción
- definición de listo por rama
- evidencias requeridas antes de avanzar

## Criterios de aceptación

- existe política clara por rama
- existe test plan asociado
- staging tiene propósito verificable
